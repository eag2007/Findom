# Серверная часть поисковика Findom

## Описание

Сервер разделен на несколько блоков. Блок контроллеров обрабатывающих ```url```. 
А также 3 основных блока составляющих ядро (```core```).<br>
- **Краулер** - скачивает страницы, парсит html, достает слова.
- **Индекс** - бъет на группе и ассоциации сохраняет в кэш память
- **Поиск** - ищет данные в кэш памяти по запросу

## Схема

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│   Краулер   │────▶│   Индекс     │────▶│   Поиск     │
│  (Spider)   │     │  (Storage)   │     │  (Query)    │
└─────────────┘     └──────────────┘     └─────────────┘
↓                    ↓                    ↓
Скачивает          Хранит данные        Ищет по запросу
страницы           в базе данных        пользователя
```
